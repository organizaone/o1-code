## Stop on first key

Keypress path. `useLogoAnimation` subscribes through the existing `useKeypress` hook
(`KeypressContext`), active only while an animation is playing and not yet stopped. A key sets
`stop`; `AnimatedLogo` rests at once and calls `onDone`; the hook marks itself done and returns
`undefined`, so the header goes back to `O1Logo` with the layout's blank row. The variant is chosen
in a `useState` initializer, so it is decided once per session and never restarts (not even after
`/clear` empties the history). A first history item or a resize under 80 columns also ends it for
good. Focus and mouse sequences never reach keypress subscribers, so they do not stop it.

## Decisions where the brief was silent

- **Grid origin.** The mock drew from column 1; the port draws from column 0 so the rest frame lines
  up with `renderLogoRows()`. Seeds that depended on the column (`compila`, `chuva`) use the mock's
  numbering, so the pixels are the same. A script comparing every frame of every variant against the
  mock's own JS (extracted from `ops/logo-anim-mock.html`) finds 0 differences except the one below.
- **`digita` cursor after the dot (deviation from the mock).** In the mock, once the word is typed
  the cursor is placed at `last.x + 2`, which is outside the grid, so the blinking the description
  promises never showed. The port puts it right beside the dot (column 29), inside the "static width
  plus one" limit. 32 pixel differences (8 frames x 4 rows), all this cursor.
- **`bola` frame 55**: the mock computed `k = -1` and the ball was hidden for that frame; kept.
- **Colour mapping**: mock white-ish text is `primary`, amber `warning`, teal drop head `code`, the
  dark teal drop tail and the compile noise `muted`, the tetris flash `bright` (primary, bold).
- **Frame width**: `paintLogoFrame` returns 30 columns per row (29 of the logo plus one), no trimming;
  the rest frame's first 29 columns equal `renderLogoRows()` in text and colour. Spaces take the
  colour of the preceding run and never a background.
- **`frame(t)` for `t >= length`** returns `restFrame()`; `restFrame()` is also exported.
- **`pickLogoAnimation`**: `off` is `undefined`; a known name is itself; `random`, `undefined` or an
  unknown value draws one (`Math.floor(random() * 8)`, clamped).
- **Setting**: `showInDialog: false`, so no option labels need translation (the brief asked for no
  new user-facing strings); labels are the raw values. `requiresRestart: false` (it is read at
  start only anyway).
- **Height**: chose "the pinned header renders its blank rows itself" (smallest diff that keeps the
  height fixed in both states and is testable at `AppHeader` level).
