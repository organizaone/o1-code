# Security policy

## Reporting a vulnerability

Report security issues privately, through GitHub's private vulnerability reporting:
[open a new advisory](https://github.com/organizaone/o1-code/security/advisories/new).

Do not open a public issue for a vulnerability. Include what you found, how to reproduce it, the
version or commit you tested, and the impact you expect. You will get an answer in the advisory
thread.

This channel is for security issues only. Bugs and feature requests go to the issue tracker.

## Supported versions

Only the latest release and `main` receive security fixes.
